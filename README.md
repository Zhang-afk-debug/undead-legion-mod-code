# Mortilegion

一个 Minecraft 模组，添加不死军团相关的生物、Boss、剧情和机制。  
[1.20.1] | [forge47.1]

## 目录

- [环境要求](#环境要求)

## 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Java | 17 | **必须**，其他版本（如 8、11、21）会导致编译失败 |
| Minecraft | 1.20.1 | 请与模组目标版本一致 |
| Git | 任意 | 用于克隆仓库 |
| 网络 | 可用 | Gradle 首次构建会下载大量依赖（约 500MB+） |
